# Project Guidelines & Rules

- **User Approval Required Before Modifying Codebase**:
  - Always create/update an Implementation Plan (`implementation_plan.md`) describing proposed changes across all files and components.
  - Set `request_feedback = true` so the user is presented with the plan and has full authority to review, approve/accept, or reject the proposed changes before any codebase files are modified.
  - Never execute file modifications on codebase files until the user explicitly accepts/approves the plan.
